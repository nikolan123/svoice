S Voice Server

Bringing S Voice back to life

What is this?

A custom server that makes S Voice work again locally. Works with S Voice versions that shipped until Android 5, tested with version 11.2.2.0.x.

Uses OpenAI Whisper for transcription and an LLM for intelligent responses.

Tested Devices

Galaxy S4 I9505
Galaxy Note 3 N9005
Galaxy S3 Mini I8200
Galaxy S3 Neo I9301I
Galaxy S4 Mini I9195
